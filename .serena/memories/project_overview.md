Purpose: Python library for parsing IBM JCL into structured Python objects, with validation, PROC loading, continuation handling, and procedure explosion. Structure: core package under jclparser/ with parser.py, model.py, validators.py, parameter_validators.py, explosion.py, proc_loader.py, continuation_handler.py, utils.py, system_symbols.py, jcl_file_type.py, and plugins/. Current codebase has significant compatibility-sensitive public API surface exposed via jclparser/__init__.py and utility modules; refactors should preserve wrappers before removals.
